<confirmed_root_cause>
DO NOT re-investigate. Youtarr writes NESTED:
Channel/{Channel - Title - videoID}/{Channel - Title [videoID]}.mp4|.nfo|.jpg
In a Jellyfin 10.10 TV Shows library each per-video subfolder is resolved by the
server as a SEASON named after the folder. YoutarrEpisodeNfoProvider already sets
Episode.ParentIndexNumber = upload-year, but a metadata provider cannot reliably
override a folder-derived season (issue #14080). Result: a mix of year-seasons,
stray numeric seasons ("Part 2" becomes Season 2), and per-video-named seasons.
Youtarr's nested grouping CANNOT change to flat (user-confirmed).
</confirmed_root_cause>

CANONICAL SEASON CREATION (verbatim shape from v10.10.7
SeriesMetadataService.CreateSeasonAsync — replicate for get-or-create):

      Name = seasonName,                 // "Season 2024"
      IndexNumber = seasonNumber,        // the year, 2024
      Id = LibraryManager.GetNewItemId(
          series.Id + (seasonNumber ?? -1).ToString(CultureInfo.InvariantCulture) + seasonName,
          typeof(Season)),
      IsVirtualItem = false,
      SeriesId = series.Id,
      SeriesName = series.Name,
      SeriesPresentationUniqueKey = series.GetPresentationUniqueKey(),
