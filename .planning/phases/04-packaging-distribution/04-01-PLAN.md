jprm plugin build MUST run from the directory containing build.yaml
(Jellyfin.Plugin.Youtarr/). From repo root it is a silent no-op (exit 0, no ZIP).

jprm command surface used by this plan:
  jprm plugin build . -o <output-dir>
      -> writes <output-dir>/youtarrmetadata_1.0.0.0.zip
                <output-dir>/youtarrmetadata_1.0.0.0.zip.md5sum
                <output-dir>/youtarrmetadata_1.0.0.0.zip.meta.json
      ZIP contents (flat, no subdir): meta.json + Jellyfin.Plugin.Youtarr.dll
  jprm repo init <manifest-path>
      -> writes an empty JSON array []. FAILS if file already exists -> guard with [[ ! -f ]].
  jprm repo add <manifest-path> <zip-path> --plugin-url <url>
      -> appends/updates a versioned plugin entry; computes MD5 checksum of the ZIP.

Slug/version facts (do not hardcode beyond VERSION variable):
  name "YoutarrMetadata" -> slug "youtarrmetadata" (ZIP filename prefix)

  version source of truth: build.yaml version: "1.0.0.0" (do NOT add <Version> to csproj)

manifest.json schema (live-verified) — top-level JSON array; each entry:
  { guid, name, description, overview, owner, category,

  checksum is the MD5 of the ZIP (jprm computes it)
