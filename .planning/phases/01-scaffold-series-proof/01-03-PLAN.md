<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Host OS -> Docker daemon | Starting the daemon needs sudo; the agent surfaces copy-paste commands rather than escalating |
| Plugin DLL -> Jellyfin host process | A mis-versioned/malformed DLL can leave the plugin Malfunctioned or destabilize the server |
| Fixture media -> plugin (read-only mount) | Media is mounted :ro so the plugin physically cannot mutate user files during the test |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-06 | Elevation of Privilege | Docker daemon start (sudo) | transfer | Per project policy, the agent never runs sudo; README provides copy-paste commands for the operator to run, keeping privilege escalation under human control |
| T-01-07 | Tampering | User media files during scan | mitigate | media mounted read-only (:ro) in docker-compose; verified by Task 1 grep; library configured with "Save metadata to media folders" disabled |
| T-01-08 | Denial of Service | Plugin Malfunctioned crashes/destabilizes server | mitigate | restart:"no" container is disposable; README documents failure signatures mapping to root causes (ExcludeAssets/targetAbi/constructor) for fast diagnosis |
</threat_model>
