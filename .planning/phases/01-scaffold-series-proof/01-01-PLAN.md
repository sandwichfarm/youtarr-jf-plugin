<objective>
Scaffold the Jellyfin.Plugin.Youtarr .NET 8 class library so it compiles and produces a single plugin DLL that Jellyfin 10.10.x will load as "Active". This is the first slice of the Walking Skeleton: the application (plugin) exists, builds, and boots inside Jellyfin with a stable identity and a config page hook — even before it does any metadata work.

Purpose: PLUG-01 requires the plugin to load as Active with no errors. Every later slice (Series resolution, Episodes, artwork) is untestable until the DLL loads. This plan establishes the project skeleton, the permanent GUID, and the packaging descriptor that all subsequent phases build on.

Output: A buildable plugin project (csproj, Plugin.cs, Constants.cs, PluginConfiguration.cs, configPage.html, build.yaml) plus a .gitignore. After this plan, `dotnet publish -c Release` yields Jellyfin.Plugin.Youtarr.dll.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Jellyfin host → plugin DLL | Jellyfin loads and executes the plugin in its own process; a malformed/mis-versioned DLL can destabilize the host |
| NuGet → build | Package-manager installs of Jellyfin.Controller/Jellyfin.Model cross into the build |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Denial of Service | Plugin load (TypeLoadException from bundled runtime DLLs) | mitigate | ExcludeAssets=runtime on both Jellyfin refs; Task 3 asserts no runtime DLLs in publish output |
| T-01-02 | Tampering | Plugin identity / config path (GUID drift) | mitigate | Single generated GUID mirrored in build.yaml and Plugin.cs; Task 2 verify asserts equality |
| T-01-SC | Tampering | NuGet installs (Jellyfin.Controller, Jellyfin.Model) | accept | RESEARCH Package Legitimacy Audit verified both on the NuGet registry as official Jellyfin packages; no [ASSUMED]/[SUS]/[SLOP] packages — no blocking checkpoint required |
</threat_model>
