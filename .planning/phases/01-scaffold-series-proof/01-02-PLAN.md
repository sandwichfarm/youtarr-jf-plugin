<objective>
Make channel folders resolve as correctly-named Series and stop Youtarr `__prefix` grouping folders from becoming phantom Series. This is the core capability slice of Phase 1: after this plan, the plugin actually does its Phase-1 job — a Shows library pointed at a Youtarr download folder shows each channel subfolder as a Series named after the channel, and `__kids` / `__music` folders are silently skipped.

Purpose: Delivers LIB-01 (channel folder → Series), SER-01 (name from folder, fallback to NFO `<studio>`), SER-02 (metadata synthesized despite no tvshow.nfo), and CMP-03 (`__prefix` folders don't break resolution). Pure string/path/XML logic is extracted into PathUtils so it is unit-testable without a running Jellyfin server.

Output: PathUtils, YoutarrPrefixIgnoreRule (IResolverIgnoreRule), YoutarrSeriesNfoProvider (ILocalMetadataProvider<Series>), Plugin.RegisterServices wiring the ignore rule, and an xUnit test project covering the testable logic.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Filesystem (Youtarr media) → plugin | Plugin reads attacker-influenceable NFO XML and folder/file names from disk; must never crash the scan or mutate files |
| Library scanner → ignore rule | A faulty ShouldIgnore could hide real channels or expose phantom ones |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-03 | Denial of Service | YoutarrSeriesNfoProvider (malformed NFO crashes scan) | mitigate | ReadStudioFromMovieNfo swallows parse exceptions to null; GetMetadata wraps NFO read in try/catch and falls back to folder name; unit tests cover malformed NFO |
| T-01-04 | Tampering | User media files (plugin must be read-only) | mitigate | Provider and PathUtils only read (Directory.GetFiles / XDocument.Load); no write/move/rename APIs used — enforced by code review and absence of write calls |
| T-01-05 | Spoofing | Phantom Series from __prefix folders / hidden real channels | mitigate | YoutarrPrefixIgnoreRule limited to directories with exactly the "__" prefix; unit tests assert single-underscore and files are NOT ignored |
</threat_model>
