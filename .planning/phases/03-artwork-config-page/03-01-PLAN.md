Deliver ART-02: a custom `YoutarrSeriesImageProvider : ILocalImageProvider` that surfaces the channel `poster.jpg` as the Series **Backdrop** image. Purpose: This is the only custom artwork code in Phase 3. Youtarr writes only `poster.jpg` (no `fanart.jpg`/`backdrop.jpg`), so the built-in backdrop search finds nothing — the plugin reuses `poster.jpg` as a "better than blank" backdrop.
Output: One new provider class, an explicit DI registration (conservative safety net), and an xUnit test file proving backdrop emission, graceful missing-file behavior, and Series-only support.
