<objective>
Build the testable foundation of the Episode pipeline: a `YoutarrVideoData` DTO, a pure `YoutarrNfoParser` that maps a Youtarr `<movie>` NFO into that DTO with robust date validation, and the two new `PluginConfiguration` fields the provider will read. This is the contract layer — the Episode provider in 02-03 consumes the parser output without re-parsing XML.

Purpose: Isolating NFO parsing from Jellyfin types (the same pattern as Phase 1's PathUtils) makes every field mapping, date-fallback edge case, and UTF-8/entity-decoding concern unit-testable without a running server. EPI-07's "no crash" guarantee is enforced here at the parse boundary.

Output: `Models/YoutarrVideoData.cs`, `Parsers/YoutarrNfoParser.cs`, `PluginConfiguration` additions, and `YoutarrNfoParserTests.cs` (15+ cases), all green in Release.

Depends on 02-01 only as a gate: the live probe must pass (or its fallback be recorded) before this contract layer is worth building. No code from 02-01 is consumed.
</objective>
